# 几何面积视频：已确认的制作经验

此案例用于理解默认偏好的来源和容易出错的实现位置。新任务仍应分析其自身题目、构图与动作。

## 参考及数学机制

参考为“图解数学”的[简单转一转，巧用对称思维秒出答案！](https://xhslink.cn/o/6UdAws5qBEh)。已读取的公开视频为约 21.7 秒、720×1284、30 fps。原链接未来可能不可访问；本文件的数学描述可独立用于理解机制，不代表未来再次检查过原片。

正方形 A、B、C、D 依次为左上、右上、右下、左下，O 为中心，M 为底边 DC 中点。大圆弧以 C 为圆心，半径为边长；半圆以 DC 为直径；对角线 AC 穿过中心。

1. 三块蓝色区域包含：上方曲边区域、左侧曲边区域、半圆右上弓形。
2. 右下蓝色弓形绕 **M 逆时针旋转 90°**，落到左下；其端点 O、C 分别移动到 D、O。
3. 左侧相接的两块蓝色区域沿 **AC 翻折**到右上，与上方原有蓝块拼成三角形 ABO。
4. 正方形边长 10，AB=10，O 到 AB 的高为 5，因此蓝色总面积 `10×5÷2=25`。一般边长 a 时为 `a²/4`。

不能把第一步误写为绕 O 旋转；第二次变换是沿 AC 的空间翻折，不是任意平面旋转。二维实现可投影空间翻折：点 `(x,y)` 在 `x=y` 轴方向的分量不变，垂直分量乘 `cos(πp)`，p 从 0 到 1。中途投影压扁，最终镜像拼合；验证真实图块和完成变换后的面积，不要求投影每帧面积不变。

## 锁屏构图的起点

| 参数 | 本案例最终值 |
|---|---|
| 画幅 | 1080×1920 |
| 正方形边长 | 620 px |
| 左上角 | x=230，y=860 |
| 水平中心 | x=540 |
| 题目/步骤提示 | 中心 x=540，基线 y=752 |
| 答案 | 中心 x=540，基线 y=1665 |
| 视觉 | 深黑背景，白色细线，蓝色填充，金色短提示 |

初版 x=210、边长 620，中心实际为 520，确实向左偏了 20 px。改为 `x=(1080−620)/2=230`，几何边界左右间距均为 230 px。栅格描边会各向外扩展约 2 px，因此测像素时要对称地计入描边，不能混用边线中心与像素外缘。

只对齐标题不能修正主体偏移。保留顶部时钟空间也不意味着垂直方向必须居中：这里明确要求**水平居中、整体下移**。检查整段变换的外接范围，包括整体三角形旋转时超出原正方形的部分。

## 首帧与紧凑节奏

最终首帧从第 0 帧起就有完整图形、三块蓝色、边长 10 和“求蓝色面积”。首帧封面与视频画面一致；标题 2.2–2.5 秒淡出。

曾经把开场改为封面，却保留了旧绘图时间轴：第 3 秒题目消失，第 7.65 秒才出现下一步提示，中间约 **4.67 秒完全静止**。正确修复是重新排布动作和提示的开始时间，不是只加快播放，也不是用无关闪烁掩盖停顿。

最终 16.5 秒时间轴：

| 时间 | 事件 |
|---|---|
| 0–2.5 s | 完整出题，最后 0.3 秒题目文字淡出 |
| 2.7–3.35 s | 连接辅助对角线 |
| 3.55–5.35 s | 弓形旋转 90°，仍给足 1.8 秒 |
| 5.8–8 s | 沿对角线翻折，仍给足 2.2 秒 |
| 8.6–9.8 s | 整体三角形转动展示 |
| 10–11.2 s | 三角形转回便于计算的位置 |
| 11.2–12.3 s | 淡去内部拼接线，显示底与高 |
| 13–16.25 s | 显示一行算式并在结尾淡出 |
| 16.5 s | 视频结束 |

解题中间不再有持续 0.6 秒以上的完全静帧；开头约 2.2 秒用于读题，结尾约 2.5 秒用于读答案。这是本案例的检查结果，不是其它教学题必须达到的静帧阈值。

## 值得保留的工程做法

- 一个场景函数按时间生成图形，网页与离线导出共用；SVG 路径和文字由数据生成。
- 用一个 `TIMELINE` 集中管理辅助线、旋转、翻折、清理、答案与结束。重新剪辑时同步修改字幕、跳转按钮、DURATION 和帧数。
- 以多边形数值面积、变换后面积和最终三角形覆盖情况核对证明；旋转和翻折中间帧另做视觉检查。
- 用确定性 SVG/帧的连续相等区间定位真实停顿。不要把“有字幕在淡入淡出”误当成图形一直在解释新内容。
- MP4 核验结果：1080×1920、30 fps、16.5 秒、495 帧、H.264/yuv420p、无声。短标题、比例、配色、时长均可按下一条题目调整。
