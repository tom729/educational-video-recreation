# 跨 Agent 与工具适配

本 Skill 是制作指令、默认预设和核验脚本的集合，不包含付费服务凭据，不自带视频生成模型，也不保证目标 Agent 天生具备图像、语音或导出能力。

## 导入方式

- 支持 Agent Skills 目录的环境：把整个 `educational-video-recreation/` 放入该环境规定的技能目录，保留相对结构。确认它能发现 `SKILL.md`；有的环境需要刷新会话。
- 支持压缩包导入的环境：导入发布 ZIP；如果只接受目录，先解压。不假定所有工具都支持直接上传 ZIP 安装。
- 没有技能系统的 Agent：将目录作为项目附件，明确要求它先读取 `SKILL.md`，再读取当前模式所需引用文件。只有主文件而没有 `references/` 不能完整恢复规则。
- `agents/openai.yaml` 仅是可选界面元数据；其他 Agent 可以忽略它。核心流程不依赖 Codex 私有 API。
- 具体目录、刷新方式和 API 能力按目标工具的当前说明确认，不向未确认的第三方系统自动安装或上传。

## 能力与替代

| 制作能力 | 优先路径 | 不可用时 |
|---|---|---|
| 读取来源 | 浏览器、搜索、论文/文档读取工具 | 使用用户给的资料；未核实内容留在研究记录，不补造事实 |
| 中文配音 | 当前授权可用的 TTS 或配音素材 | 完成脚本、读音表和无声预览，明确声音待补，不假称有配音 |
| 音频测时 | ffprobe、音频工具或编辑器 | 用该工具实际时长；不能以字数估时冒充实测 |
| 可控动画 | SVG/Canvas、动画引擎、三维工具、剪辑软件 | 选能准确表达机制的方案；没有渲染工具就交付可执行源码及未完成说明 |
| Blender 3D 元素 | Blender 自带 Python（`bpy`）；见 [建模与渲染流程](blender-production.md) | 检查版本与实际渲染能力；缺失时交付待渲染脚本，不声称已产生三维成片 |
| 视频导出 | FFmpeg 或合适编码器 | 使用目标环境导出工具并核对等价参数 |
| 视觉验收 | 截图/图像读取/视频预览 | 导出关键帧供审阅；不能宣称看过无法查看的画面 |
| 音频试听 | 音频感知工具或用户允许的试听 | 只报告波形/数值检查，不宣称发音和语气已听验 |

附带核验脚本需要 Python 3 与 PATH 中的 `ffmpeg`、`ffprobe`，仅使用 Python 标准库。它不安装软件、不调用网络、不播放音频。缺依赖时先报告具体缺项，再用当前授权范围内的安装或替代方式；不擅自注册服务、购买额度或上传私有素材。

不得写死某个用户主目录、操作系统字体路径、旧项目的 localhost 端口、语音服务令牌或原有视频资产位置。中文字体选择目标机器可用且可合法分发的字体，并核对实际字形。化学下标、罕见字等要检查是否缺字。

## 调用示例

完整制作：

> 使用 educational-video-recreation，为“汽车是金属的，为什么还能躲雷？”制作中文竖屏科普视频。按 Skill 的日常科普预设执行，不露品牌，交付 MP4、真实首帧封面、字幕、源码和默认暂停的预览。

明确分阶段：

> 使用 educational-video-recreation，先核对资料并输出解说稿与分镜；我确认后再生成配音和画面。

指定开场：

> 使用 educational-video-recreation，按项目里已确认的脚本，只做开场样片。不要自动播放。

定点修复：

> 使用 educational-video-recreation，修复第 3 段结尾尾音被切断的问题，保留其他原音，并同步字幕和时间轴。

这些例子说明如何调用，不授权 Agent 在导入 Skill 时直接制作或发布视频。
