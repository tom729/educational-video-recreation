# Blender：从真实结构到可解释的 3D 动画

需要立体结构、内部剖面、遮挡关系、机械装配、吊装或真实镜头视差时读取。默认优先用 Blender Python（`bpy`）程序化创建和动画化 3D 元素；已经有合适的三维工程时沿用，不为使用 Blender 重建所有资产。平面箭头、字幕和图表可在合成层制作。

## 1. 建模依据与环境

先从研究记录和分镜提取部件清单、尺寸比例、连接方式、运动轴、材料与可简化部分。优先真实照片、工程剖面、官方模型和机构资料。不能凭技术感外观编造内部原理；估计尺寸和示意夸张要记录。已有模型先确认来源、授权和比例，再导入。

检查 `blender --version`；在当前安装版本上验证脚本，记录版本、渲染器和设备。Blender 的 Python 与宿主 Python 分开，`bpy` 脚本通常由 Blender 自带 Python 执行。先检查本机可用能力，不假定有 MCP 插件、GPU 或第三方插件。无 Blender 时按授权安装或交付待渲染源码，并明确没有生成 `.blend` 或成片；不要冒充完成。

## 2. 用部件构建结构，而不是用纹理假装结构

- 用 `bpy.data` 或 `bpy.ops` 建立网格，按实际关系使用曲线、阵列、实体化、布尔或手工截面；不必把所有形状都做成高面数。
- 部件使用稳定名字与集合；尺寸、厚度、间隙、材质、相机和时间放在参数区。使用一致单位，注明示意比例；需要时应用缩放，避免倒角和法线失真。
- 空心件必须有内腔、壁厚和端面。隧道管节应能看出通行空间与截面，不能靠两根长条或一张贴图代表整个箱体。
- 接口单独建模：端面、密封件、接触面、连接或锁紧部件按查证的具体工法呈现。不同工程的密封和连接步骤不能通用套用。
- 转动对象的原点位于真实轴心；连杆、吊索、吊点、支座建立正确父子或约束关系。吊装时先承重绷紧，再平稳下放、对位、接触和卸载；不能让箱体穿过海床、吊索松着却悬空受力，或靠突变缩放完成安装。
- 在最终相机下核实轮廓、遮挡、法线和穿插。剖切与爆炸图是教学展示方式，不暗示物体在真实运行中会透明或分离。

## 3. 材质、照明与科技感

使用可读的金属、玻璃、橡胶、混凝土等材质差异；倒角与合理粗糙度帮助识别边缘。少量有方向的主光、补光和轮廓光通常足够。真实比例和结构优先于炫光、漂浮网格、过亮霓虹和装饰性粒子。

预览可用 EEVEE；涉及透明、折射、多次反射或细致光照时按需要选 Cycles。说明渲染器的表现边界：好看的光线不是光学仿真结果。固定色彩管理配置，检查合成后的亮度与边缘，不直接把线性渲染数据当作普通显示图使用。

## 4. 动画与整体—局部衔接

以配音实测后的时间轴为准。若 Blender 起始帧为 1，则 `t=(frame-1)/fps`；第一帧对应成片的第 0 帧。总帧数由完整配音和尾部缓冲确定，帧区间包含两端，避免多一帧或少一帧。

关键帧、约束或确定性的逐帧状态均可。镜头到位时可缓入缓出，连续运转的转子或匀速推进通常用线性插值；检查贝塞尔过冲。物理模拟先烘焙并交付缓存，不依赖未烘焙的随机播放结果。

局部放大时先让观众知道它在整体哪里，再沿同一对象连续移动或用遮罩展开。可用第二相机渲染局部，将整体缩到小窗并保持部件配色与定位线；不要只把整体模型非等比拉伸。新旧标注错峰出现，避免全屏交叉淡化导致双重轮廓。镜头运动不能把关键接口遮住。

## 5. 相机与安全框

结构讲解优先考虑正交或较弱透视，需要尺度纵深时使用透视。日常竖屏内容框仍为顶部 20%、底部和左右各 10% 留白；背景可以铺满，文字、主体、标注、发光外沿和运动范围须留在框内。

用 `bpy_extras.object_utils.world_to_camera_view` 将求值后的对象包围盒投影到画面。该函数原点在左下，所以安全范围为 `x∈[0.1,0.9]，y∈[0.1,0.8]`，不是屏幕自上向下的 y。检查深度为正、相机裁切范围、整个运动过程；修改器/骨骼变形需使用依赖图求值后的几何。包围盒检查只覆盖几何，不覆盖景深、运动模糊、光晕、投影、字幕或合成层，仍需检查最终帧。

## 6. 起步脚本与渲染

附带 [scripts/create_blender_scene.py](../scripts/create_blender_scene.py) 创建一个空心套筒、轴和端环的无品牌拆解示例，含材质、相机、灯光、动画及全帧几何安全框检查。已在 Blender 4.5.7 LTS / Cycles CPU 上生成工程并完成首、中、末三张试渲染；其他版本仍需运行验证。它是验证工具链的素材模板，不是实际产品模型，也不是含配音、问题标题和字幕的完整视频。按研究结果替换部件与动作，不把示例结构套到所有选题。

从 Skill 根目录运行，输出目录应是新的目录：

```bash
blender --background --factory-startup --python-exit-code 1 \
  --python scripts/create_blender_scene.py -- \
  --output outputs/blender-element-v1 --frames 90 --fps 30
```

低成本抽帧试渲染可增加 `--render-samples --resolution-percent 25 --samples 8`。该比例会保存到示例工程，正式导出前必须恢复 100%。脚本拒绝覆盖已有输出目录，且只允许后台执行，避免清空交互工作中的场景。

工程确定后逐帧渲染 PNG/RGBA 或需要的 EXR 序列，再合成背景、标题、字幕和声音。Blender 命令行参数按顺序执行，渲染开关放在参数设置后：

```bash
blender --background outputs/blender-element-v1/scene.blend \
  --render-output //frames/frame_ --render-format PNG \
  --frame-start 1 --frame-end 90 --render-anim
```

透明素材需先合成背景再编码为 H.264/yuv420p，不能把该编码当作保留透明的中间格式。多个镜头用统一尺寸、帧率和色彩配置。合成后真实首帧包含完整封面问题与场景，不能把此模板的无字首帧直接当作成品封面。

## 7. 验收与交付

先渲染首帧、重要机制中间帧和结尾，再做全片；抽查转场边界、接触瞬间和快速运动段是否跳动、穿插、错误受力或发生降噪闪烁。全帧数值扫描不能替代视觉验收。继续使用主流程的视频和音频核验规则，预览默认暂停，不自动播放样片。

交付建模/动画脚本、参数、`.blend`、素材来源、纹理/字体或可复现获取方式，以及必要缓存；使用相对路径，合法可打包的外部资源按需打包。把启动和渲染命令、Blender 版本、引擎、设备及检查范围记入 `validation.md`。可用 GLB 供网页交互，但需实测材质、动画及约束的导出结果，不能把 GLB 当作无损 `.blend` 替代品。

对现有视频只改画面时复用配音与既定时间轴；模型修正后重新检查所有引用该模型的镜头。公开 Skill 仅收录通用规则与模板，不夹带私人项目、未获授权模型或付费素材。

官方接口参考（实现时以安装版本为准）：[命令行渲染](https://docs.blender.org/manual/en/4.5/advanced/command_line/render.html)、[命令行参数](https://docs.blender.org/manual/en/4.5/advanced/command_line/arguments.html)、[相机投影工具](https://docs.blender.org/api/4.5/bpy_extras.object_utils.html)。
